# VICHAR_AI

Vichar AI is an emotionally aware wellness companion with Arpita and Biniit,
context-aware conversations, mood support, and a calming private journal.

The journal now includes a password-controlled diary-opening experience,
client-side AES-256-GCM encryption, encrypted autosaved drafts, handwritten
font choices, cute paper themes and decorations, and locally generated rain,
wind, forest-bird, ocean-wave, fireplace, and deep-focus soundscapes.

See [JOURNAL_UPGRADE.md](JOURNAL_UPGRADE.md) for setup and privacy details.
